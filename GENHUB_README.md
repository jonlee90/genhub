# GenHub - Construction Management Platform

Modern construction project management for general contractors, combining task management, bid coordination, material tracking, and client communication in one PWA that works offline.

---

## Who It's For

- **General Contractors** - Multi-project oversight, bid management, subcontractor coordination
- **Project Managers** - Daily operations, task tracking, progress monitoring
- **Field Workers** - Daily reports, material tracking, expense submission
- **Subcontractors** - Bid submissions, task collaboration
- **Clients** - Real-time project visibility through dedicated portal

---

## Core Features

### Project & Task Management
- **Visual Timeline** - Subway-map style phase tracking across all projects
- **Flexible Views** - Kanban boards, list view, or Gantt chart timelines
- **Task Dependencies** - Link tasks and track blockers
- **Smart Assignment** - Primary + multi-assignee support with workload visibility
- **Real-time Updates** - Live sync across team devices

### Bid & Subcontractor Management
- **AI-Powered Bidding** - Auto-generate scope descriptions, invite subs via email/SMS
- **Bid Comparison** - Side-by-side analysis with AI recommendations
- **One-Click Award** - Instantly create tasks for winning bidders
- **Sub Database** - Track performance and contact info

### Materials & Expenses
- **Home Depot Integration** - Real-time pricing, availability, and product search
- **Task-Level Tracking** - Link materials to specific work items
- **Receipt AI** - Auto-parse receipts and match to expenses/materials
- **Budget Monitoring** - Track spending vs. budget in real-time

### Daily Operations
- **Site Reports** - Weather, crew, work completed, safety notes
- **AI Summaries** - Auto-generate team and client report versions
- **Photo Documentation** - Spatial photo mapping with 3D model overlay
- **Expense Approval** - Submit, review, and approve with receipt capture

### Communication & Collaboration
- **Project Chat Rooms** - Organized conversations per project/task
- **Direct Messaging** - Team-wide communication
- **KakaoTalk Integration** - Seamless messaging for Korean teams
- **Smart Notifications** - Configurable alerts for key events

### Client Portal
- Dedicated client view with project timeline
- Daily summary reports
- Photo gallery with spatial context
- Document access and change order approvals
- Invoice and payment history

### Analytics & Insights
- **KPI Dashboards** - Budget, schedule, material usage, team performance
- **Project Health** - Real-time status indicators across portfolio
- **Top Performers** - Track productive projects and team members
- **Subcontractor Metrics** - Evaluate reliability and quality

### Change Management
- Create and track change orders
- AI impact analysis (cost + schedule)
- Client approval workflow
- Automatic budget and task updates

---

## Why GenHub?

**Purpose-Built for Construction** - Not adapted from generic PM tools. Features like bid management, daily site reports, and material tracking designed for contractors.

**AI-Powered Efficiency** - Automate bid scopes, daily summaries, receipt parsing, and impact analysis. Save hours weekly on admin work.

**Works Offline** - Progressive Web App works at job sites with poor connectivity. Syncs automatically when online.

**One Source of Truth** - Replace scattered emails, spreadsheets, texts, and paper forms with centralized, searchable data.

**Professional Client Experience** - Polished reports, transparent portals, and organized communication win repeat business.

## Getting Started

1. **Sign Up** - Create account and company profile
2. **Create Project** - Add your first project with basic details
3. **Build Team** - Invite members and set roles/permissions
4. **Start Working** - Add tasks, track materials, submit reports
5. **Enable Client Portal** - Share project access for transparency

---

## Technical Details

**Stack:** Next.js 15, React 19, Supabase, Tailwind CSS
**Platform:** Progressive Web App (PWA) - works on iOS, Android, desktop
**Offline:** Full offline capability with automatic sync
**Security:** Enterprise-grade encryption, role-based access, regular backups
