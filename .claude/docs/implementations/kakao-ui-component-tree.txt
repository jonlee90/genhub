Animation Timeline
==================

Component Mount:
0ms    → Opacity 0, Y offset +20px
400ms  → Opacity 1, Y offset 0 (spring)

Status Badge:
0ms    → Scale 1, opacity 0
100ms  → Scale 1, opacity 1 (stagger delay)
Loop   → Pulse: 1 → 1.2 → 1 (2s ease)

Sync Toggle:
Click  → Loading spinner shows
API    → Server action completes
Success → Switch animates (500ms spring)
        → Color transition (300ms)
        → Icon fade (200ms)

State Transition (Connect/Disconnect):
0ms    → Current state scale 1, opacity 1
300ms  → Fade out: scale 0.95, opacity 0
300ms  → Fade in: scale 0.95 → 1, opacity 0 → 1


Responsive Breakpoints
======================

Mobile (< 640px):
  - Full width buttons
  - Stacked badges
  - Smaller icon sizes (h-4 w-4)
  - Reduced padding (p-4)

Tablet (640px - 1024px):
  - Standard layout
  - Icon sizes (h-5 w-5)
  - Medium padding (p-6)

Desktop (> 1024px):
  - Max width container
  - Larger icons (h-6 w-6)
  - Generous padding (p-8)
  - Transform hover effects enabled
