## Key Component Patterns

### Modal Components
Use **BaseModal** for all modals (never use Dialog):
- `BaseModal` - Base modal component
- `BaseModalHeader` - Modal header with title and close button
- `BaseModalFooter` - Modal footer with action buttons
- `ResponsiveModal` - Responsive modal for mobile/desktop

### Mobile Components
Mobile-optimized components in `mobile/`:
- `BottomSheetModal` - Mobile bottom sheet
- `FloatingActionButton` - FAB for primary actions
- `MobileInput` - Touch-optimized inputs
- `SwipeableCard` - Swipeable cards
- `PullToRefresh` - Pull-to-refresh functionality

### Layout Components
- `Header` - Top navigation bar
- `Sidebar` - Desktop sidebar navigation
- `BottomNavigation` - Mobile bottom nav
- `MoreMenu` - Overflow menu

### UI Primitives
Located in `ui/`:
- Shadcn components (button, input, select, etc.)
- Custom components (BaseModal, FilterBar, etc.)
- Aceternity UI components (decorative effects)

## Component Usage Guidelines

### Import Patterns
```typescript
// UI components
import { Button } from '@/components/ui/button'
import { BaseModal } from '@/components/ui/BaseModal'

// Feature components (Note: tasks/ flattened as of Jan 2026)
import { TaskCard } from '@/components/tasks/TaskCard'
import { CreateProjectModal } from '@/components/projects/CreateProjectModal'
```

### Client Components
All components are client components (`'use client'`). They:
- Call Server Actions for data mutations
- Use React Query or SWR for data fetching
- Handle local state and interactions
- Never import Supabase client directly

### Icons
Use Lucide React icons only:
```typescript
import { Plus } from 'lucide-react'
// NOT from lucide-react/icons barrel import
```
