# GenHub Expense Approval Workflow

## Goal
Process expenses with receipt OCR and approvals.

## Steps
1. Submit expense with receipt
2. OCR and validation checks
3. Review and approve/reject
4. Update project budget and task costs

## Command
- `/expense {type}`

## Agents
- GenHubDomainOps
- GenHubSupabase

## Outputs
- Expense lifecycle flow
- Schema + server action checklist
- Approval and security notes
