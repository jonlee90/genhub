# GenHub Daily Report Workflow

## Goal
Capture daily site activity and summarize with AI.

## Steps
1. Collect inputs (photos, notes, tasks)
2. Generate summary + editable review
3. Store report and notify stakeholders
4. Link report to project timeline

## Command
- `/daily-report {project}`

## Agents
- GenHubDomainOps
- GenHubProductUX

## Outputs
- Report structure
- UX flow + UI states
- Permissions and visibility notes
