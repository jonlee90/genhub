# GenHub Commands

## Product & Schema
- `/feature-spec {feature}` — Feature spec + acceptance criteria
- `/db-schema {change}` — Schema + RLS design

## Domain Operations
- `/bid {scope}` — Bid lifecycle flow
- `/daily-report {project}` — Daily report workflow
- `/expense {type}` — Expense intake + approval flow

## Notes
- Commands route to GenHub subagents
- Use GenHub workflows in `.opencode/workflows/` for full delivery
